Step 1 — Your Plausible Account Setup

Do this once. Covers all your clients from one dashboard.

1
Create your account

Go to plausible.io and sign up. The Starter plan at $9/month covers up to 10,000 monthly pageviews across unlimited sites — enough for all your early clients combined.

2
Add a new site

In your Plausible dashboard click "Add a website". Enter the client's domain (e.g. freshflowjuices.com). If they're on GitHub Pages with no custom domain, enter their GitHub Pages URL (e.g. freshflowjuices.github.io/site).

3
Copy the snippet

Plausible will show you a script tag with the client's domain pre-filled. Copy it — or use the template below and fill in the domain yourself.

Step 2 — The Code Snippet

Paste this into every client's HTML file. That's all it takes.

The base snippet (standard tracking):

<!-- ══ PLAUSIBLE ANALYTICS ══════════════════════════════
     Cookie-free · No consent banner needed · GDPR compliant
     Replace [CLIENT-DOMAIN] with the client's actual domain
     e.g. data-domain="freshflowjuices.com"
     ══════════════════════════════════════════════════════ -->
<script
  defer
  data-domain="[CLIENT-DOMAIN]"
  src="https://plausible.io/js/script.js"
></script>
Where to place it: Inside the <head> tag, just before the closing </head>. It loads with defer so it never slows the page down.

With custom event tracking (WhatsApp clicks + order buttons):

<!-- ══ PLAUSIBLE — with outbound link + custom events ═══
     Use script.outbound-links.js to auto-track WhatsApp taps
     ══════════════════════════════════════════════════════ -->
<script
  defer
  data-domain="[CLIENT-DOMAIN]"
  src="https://plausible.io/js/script.outbound-links.js"
></script>

<!-- Custom event helper — call plausible('EventName') anywhere -->
<script>
window.plausible = window.plausible || function() {
  (window.plausible.q = window.plausible.q || []).push(arguments)
};
</script>
The outbound-links script version automatically tracks every click on an external link — including your WhatsApp wa.me buttons. No extra code needed on the buttons themselves. This is the version to use on all builds.

Step 4 — Tracking Custom Events

Optional but powerful — track specific button clicks as named events in your dashboard.

WhatsApp outbound links are tracked automatically. But you can also fire named events for specific actions:

On any button or link, add an onclick handler:

<!-- WhatsApp CTA button — fires "WhatsApp Click" event -->
<a
  href="https://wa.me/17587235872?text=I%20want%20to%20order"
  onclick="plausible('WhatsApp Click')"
  class="btn-wa"
>
  Order via WhatsApp
</a>

<!-- Hero CTA -->
<a
  href="https://wa.me/17587235872"
  onclick="plausible('Hero CTA Click')"
>Start My Order</a>

<!-- Menu / Pricing section button -->
<a
  href="https://wa.me/17587235872"
  onclick="plausible('Pricing CTA Click')"
>Get This Package</a>

These will appear in your Plausible dashboard under Goal Conversions once you define the goal names there. The names must match exactly.

Recommended events to track on every jamaLinks build:

WhatsApp Click Hero CTA Click Pricing CTA Click Menu View Order Form Submit PayPal Click

Step 5 — Removing GA4 & The Consent Banner

If replacing GA4 with Plausible — clean these out of the HTML.

Remove or comment out the following from the client's HTML file:

Remove these entirely when using Plausible:
<!-- 1. Remove the consent banner CSS link -->
<link rel="stylesheet" href="https://tagconcierge.github.io/consent-banner-js/dist/consent-banner.css">

<!-- 2. Remove the consent banner JS script at bottom of body -->
<script src="https://tagconcierge.github.io/consent-banner-js/dist/consent-banner.js"></script>

<!-- 3. Remove the entire consent config + GA4 script block:
     The block containing consentConfig, loadConsentState,
     saveConsentState, loadGoogleAnalytics, cookiesBannerJs
     — delete all of it. Plausible needs none of this. -->
What stays: The WhatsApp tracking function (trackWhatsAppClick) and the Google Sheets tracking URL can remain if you're using them for your own click logging. That is separate from analytics and unrelated to cookies.

Also update the Privacy Policy page — use the Plausible block in the Cookies section (already included in the legal template) and remove the GA4 cookie table.

Step 6 — Verifying It Works

Before you hand over to the client, confirm tracking is live.

1
Visit the live site

Open the client's published site in your browser. Visit two or three pages and click a WhatsApp button.

2
Check your Plausible dashboard

In your Plausible account, open the site. Go to Realtime. You should see yourself as an active visitor within 30 seconds. If you see it — it's working.

3
Confirm outbound clicks

Click any WhatsApp button on the site. In Plausible, go to Goal Conversions → Outbound Link: Click. Your click should appear with the wa.me URL. This confirms WhatsApp taps are being tracked.

4
Share access with the client (optional)

In Plausible, go to Settings → Visibility and enable the public dashboard link. Send this link to your client — they can see their live analytics without needing a Plausible account. This is your retainer deliverable.
